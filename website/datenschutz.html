Privacy policy

Effective date: September 8, 2026 · KoalaClicker 1.3.0

Local extension processing

KoalaClicker locally processes and stores website origins, selectors, names, intervals, enabled states, IDs and revisions. It reads the current page URL for document authorization and migrates older origin-plus-path keys. Local processing is still data processing.

No extension analytics, telemetry, advertising, network client, remote code or external fonts. No runtime third-party libraries; development uses npm dependencies.

Access and controls

activeTab grants temporary page access after you invoke the icon or shortcut. scripting injects packaged code into that top-level document; storage saves local settings. No standing host permissions. An event-driven background script orders storage changes. Closing the popup leaves configured clicks running; navigation stops that document until you reopen.

Settings apply across paths of the same origin and already invoked tabs. Delete removes a target. Delete all removes that website's configurations and legacy copies; an empty origin/revision record may remain. Stop all disables targets. Uninstall removes extension storage. No remote backup.

Target pages and links

Clicks may cause the target website to perform actions, submit forms or make network requests. Those are the target site's activities. Links you open to GitHub, support, legal information or future stores are governed by those services' policies. GitHub support messages may be public; avoid private content.

This website

The website stores your language choice as koalaclicker-lang in localStorage. Clear the website's site data to remove it. Assets are local and no analytics are included.

Operator confirmation needed before deployment: actual hosting provider, processing location, logged fields and complete log deletion schedule. These infrastructure facts have not been verified in this repository. Log rotation alone does not establish deletion.

Store declarations

KoalaClicker's use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including Limited Use. Browser API information serves only the visible clicker features; it is not sold, used for advertising or transferred by the extension. Firefox declares no collection/transmission outside the browser; this does not deny local processing.

Datenschutzerklärung

Stand: 8. September 2026 · KoalaClicker 1.3.0

Lokale Verarbeitung durch die Erweiterung

KoalaClicker verarbeitet und speichert lokal Website-Origins, Selektoren, Namen, Intervalle, Aktivzustände, IDs und Revisionsnummern. Die aktuelle Seiten-URL wird für die Dokumentzuordnung gelesen; ältere Origin-plus-Pfad-Schlüssel werden lokal migriert. Auch lokale Verarbeitung ist Datenverarbeitung.

Die Erweiterung enthält keine Analytics, Telemetrie, Werbung, Netzwerkclients, nachgeladenen Code oder externen Schriftarten. Sie liefert keine externen Laufzeitbibliotheken aus; Entwicklung und Prüfung nutzen npm-Abhängigkeiten.

Zugriff und Kontrolle

activeTab gewährt vorübergehenden Seitenzugriff nach deinem Aufruf per Symbol oder Tastenkürzel. scripting injiziert mitgelieferten Code in das Hauptdokument, storage speichert lokale Einstellungen. Keine dauerhaften Host-Berechtigungen. Ein ereignisgesteuertes Hintergrundskript ordnet Speicheränderungen. Das Schließen des Popups stoppt laufende Clicker nicht. Navigation stoppt das Dokument bis zum erneuten Öffnen.

Einstellungen gelten über Pfade derselben Origin hinweg und erreichen bereits aktivierte Tabs. Delete löscht ein Ziel, Delete all alle Konfigurationen dieser Website einschließlich alter Kopien. Ein leerer Origin-Datensatz mit Revision kann verbleiben. Stop all deaktiviert Ziele. Deinstallation entfernt den Extension-Speicher. Es gibt keine entfernte Sicherung.

Zielseiten und externe Links

Klicks können Aktionen, Formulare oder Netzwerkanfragen der Zielseite auslösen. Dafür gelten deren Regeln. Selbst geöffnete Links zu GitHub, Support, rechtlichen Angaben und späteren Store-Einträgen unterliegen den jeweiligen Diensten. GitHub-Supportnachrichten können öffentlich sein; keine privaten Inhalte mitsenden.

Diese Website

Die Website speichert deine Sprache unter koalaclicker-lang in localStorage. Das Löschen ihrer Website-Daten entfernt die Auswahl. Alle Assets sind lokal; Analytics sind nicht eingebunden.

Vor Deployment vom Betreiber zu bestätigen: tatsächlicher Hosting-Anbieter, Verarbeitungsort, protokollierte Felder und vollständige Löschfristen für Logs. Diese Infrastrukturangaben sind in diesem Repository nicht verifiziert. Log-Rotation belegt allein keine Löschung.
