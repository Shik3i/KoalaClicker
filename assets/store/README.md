# KoalaClicker 1.3.1 store package

**Authoritative submission folder: `assets/store/`.** `store_assets/` is retained only for historical source material.

- `listing.md`: primary English name, descriptions, single purpose, permission and Privacy Practices notes.
- `listing.de.md`: German localization.
- `firefox-reviewer-notes.md`: reproduction and reviewer steps, actual test scope and limitations.
- `chrome/01-selection.png`, `02-running.png`, `03-stopped.png`: 1280×800 Chrome images with real captures and separate captions.
- `firefox/01-selection.png`, `02-running.png`, `03-stopped.png`: 1280×800 Firefox images with real captures and separate captions.
- `icon-128.png`: existing 128×128 store icon.
- `promo-small-440x280.png`, `promo-marquee-1400x560.png`: Chrome promotional artwork.
- `preview.html`: visual index. `SOURCES.md`: provenance and capture procedure.
- `submission-checklist.md`: operator-only store/deployment handoff.

Only use current browser-specific images and current listing text. `archive/` contains old compositions, not current UI evidence. Master artwork remains editable source material. Never submit screenshots containing a prior version or describe illustrated/mockup UI as a real product capture.
